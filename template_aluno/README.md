# Missão QA — BiblioTech

## Contexto

Você foi contratado para integrar temporariamente a equipe de Quality Assurance
do BiblioTech, um sistema de biblioteca digital.

Uma nova versão do módulo de empréstimos está sendo preparada para produção.

Sua equipe recebeu uma missão:

> Avaliar se a versão atende aos requisitos e apresentar evidências suficientes
> para recomendar ou não sua liberação.

Durante a atividade serão utilizadas duas estratégias:

1. Teste de Caixa Preta
2. Teste de Caixa Branca

IMPORTANTE:

Durante a primeira etapa, utilize apenas o arquivo `requisitos.md`.

Não analise o código-fonte localizado na pasta `src/` até que o professor
autorize.

---

## Objetivos da missão

Ao finalizar o laboratório, sua equipe deverá ser capaz de:

- elaborar casos de teste a partir de requisitos;
- aplicar particionamento de equivalência;
- aplicar análise de valores-limite;
- automatizar testes utilizando pytest;
- analisar decisões e caminhos existentes no código;
- avaliar cobertura dos testes;
- registrar evidências no GitHub;
- emitir um parecer técnico de QA.
